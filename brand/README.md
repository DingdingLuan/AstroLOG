## Stable Links

- SVG: <https://dingdingluan.github.io/AstroLOG/astrolog-mark.svg>
- Transparent PNG (512 x 512): <https://dingdingluan.github.io/AstroLOG/astrolog-mark-512.png>
- Source: [web/astrolog-mark.svg](../web/astrolog-mark.svg)

These GitHub Pages links keep the same address across releases. For an immutable
copy, use the raw file URL at a specific Git tag or commit instead.

The viewer uses its bundled files so a GitHub outage cannot break its logo.
`web/` is the canonical source; `scripts/build_static_demo.py` synchronizes the
public copies in `brand/` and `docs/`. Do not edit those copies independently.

## Shared Ring Source

`source/astroslacker-ring-source.png` is a build input inherited from the
AstroSlacker family. It is not the AstroLOG product logo. The generator uses
its alpha mask for the outer ring only and replaces the center with the
AstroLOG log prompt. Keep it to reproduce the original ring without redrawing it.
